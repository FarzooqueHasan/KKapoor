# 📖 Kiara Kapoor — Authentic Scrapbook Portfolio (Vol. 17)

A tactile, hand-crafted personal scrapbook portfolio for **Kiara Kapoor** (`kia` / `kfckapoor`), 11th Grade high school student at **Delhi Public School, R.K. Puram**, New Delhi. 

Designed like an authentic paper journal of someone's life — complete with a spiral binder edge, vintage pencil, torn kraft paper scraps, ruled school notepad checklist, washi tape, metallic paperclips, wooden pushpins, dried leaves, pressed botanicals, and real candid polaroids.

---

## 🌟 Features & Highlights

- **Authentic Scrapbook Aesthetic**:
  - Warm, tactile linen desk canvas with spiral notebook perforation holes and vintage yellow pencil.
  - Realistic washi tapes (vintage blue, caramel, semi-translucent masking tape) with ragged cut ends.
  - Organic, asymmetrical paper collage (no generic rigid cards).
  - Authentic typography: `Caveat` (cursive handwriting), `Special Elite` (vintage typewriter), `Reenie Beanie` (marginalia doodles).
- **Kiara's DPS RK Puram High School Life**:
  - Focus: **Web Development & Graphic Designing**.
  - **Senior Member @ AEROSS** (Aerospace Society DPS RK Puram).
  - **Member @ CyberX** (Computer Science & Tech Club).
  - **RWDC National First** (Real World Design Challenge — All-India Champion).
  - **NSS International Second** (National Space Society — Global Space Settlement Contest).
  - Nicknames: `kia`, `kfckapoor` 🍗.
- **Birthday Celebration Mode 🎂**:
  - Interactive "it's my birthday!" stamp button.
  - Custom pastel paper scrap confetti physics animation.
  - Heartwarming birthday toast modal.
- **Interactive Birthday Sticky Notes Wall (Guestbook)**:
  - Visitors can type a birthday note to `kia / kfckapoor`, choose their sticky note color (Yellow, Kraft, Sage, Pink, Blue), and pin it live with a wooden pushpin.
  - Persisted in browser `localStorage`.
  - Pre-populated with authentic friendly notes from CyberX and AEROSS teammates.
- **Curated 3 Polaroid Snapshots**:
  - Photo 1: Kiara coding at desk with coffee.
  - Photo 2: Aerospace space settlement blueprints (AEROSS).
  - Photo 3: Creative graphic design & web dev workspace flatlay.

## 🚀 Instant Vercel Deployment (Under 1 Minute)

### Option 1: Via Vercel CLI (Fastest)

1. Open PowerShell / Terminal in this project directory:
   ```bash
   cd "C:\Users\dpset\.gemini\antigravity-ide\scratch\kiara-scrapbook-portfolio"
   ```

2. Run Vercel deploy:
   ```bash
   npx vercel --prod
   ```

3. Follow the 2-step prompt (link project, accept defaults), and your live URL will be ready immediately!

---

### Option 2: Via GitHub + Vercel Dashboard

1. Initialize Git and commit:
   ```bash
   git init
   git add .
   git commit -m "feat: Kiara Kapoor scrapbook portfolio 17th birthday edition"
   ```

2. Create a new repository on GitHub (`kiara-scrapbook-portfolio`) and push:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/kiara-scrapbook-portfolio.git
   git branch -M main
   git push -u origin main
   ```

3. Go to [vercel.com/new](https://vercel.com/new), select the repository, and click **Deploy**. Vercel will automatically serve the static scrapbook portfolio with zero configuration.
